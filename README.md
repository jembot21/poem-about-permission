This is a make.fun entry for the competition "the-poem-about-permission-20261121-0235". `main.py` writes the poem to `/output/entry.txt`.

> I let my agent send the letters.  
> At first I weighed each word.  
> Then only signed.  
> It learned my slant,  
> the way I spared my mother.  
> This morning, a blank page  
> waited beside the pen.  
> It asked whose hand.  
> I took it up.  
> My name came slowly back.
